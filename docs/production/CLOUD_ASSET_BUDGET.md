# Cloud Asset Budget — Último Barrio

Límites y presupuestos de recursos importados desde s&box Cloud Assets para mantener rendimiento a 60 FPS estables.

## Presupuestos por Categoría

| Categoría | Límite de Tamaño | Límite Triángulos (LOD0) | Draw Calls Máximos |
|---|---|---|---|
| Props Pequeños (Pickup) | < 2 MB | < 1,500 | 1 |
| Props Medios (Contenedores/Puertas) | < 5 MB | < 5,000 | 2 |
| Estructuras / Mapping Overlay | < 15 MB | < 15,000 | 4 |
| Texturas PBR (Albedo/Normal/Rough) | < 2048x2048 | N/A | N/A |
| Audios (SoundEvents) | < 1 MB / muestra | N/A | N/A |
