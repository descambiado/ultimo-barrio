# QA Playbook

Herramientas para validar sistemas sin corromper la progresión o romper reglas de producción.

## Comandos / Herramientas de QA requeridas
- ResetQaSave: Limpiar completamente el slot QA.
- ReleaseApartment [Id]: Forzar el abandono de la propiedad.
- AssignApartment [Id] [PlayerId]: Asignar bypass para 2 clientes en pruebas.
- ClearInventory [PlayerId]: Vaciar mochila.
- GiveScrap [PlayerId] [Amount]: Añadir chatarra para economía/crafting.
- GiveMoney [PlayerId] [Amount]: Añadir dinero al Wallet.
- ForceDay, ForcePreparation, ForceNight: Cambiar fase en WorldClock.
- SpawnRaider: Generar un enemigo de prueba inmediatamente.
