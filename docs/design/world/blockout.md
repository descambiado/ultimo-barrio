# World Blockout - Vertical Slice

This document contains the design overview for the world blockout.

## Components Built
- **Short Street:** Connecting the key areas.
- **Apartment Building:** Contains two apartments.
- **Portal, Stairs, Accessible Roof:** Core navigation for the building.
- **Alleyway:** Providing a secondary route.
- **Small Shop Kiosk:** Added to the street.
- **Neighborhood Meeting Area:** Open zone for encounters.
- **Defensible Accesses:** Two accesses provided.
- **Windows and Doors with Anchors:** For barricades and interactions.
- **Separated Spawns:** For enemies and resources.
- **NavMesh Volume:** For AI navigation.
