# ADR-0005 — Host autoritativo

- Estado: Accepted
- Fecha: 2026-08-02

## Decisión

Dinero, inventario persistente, propiedad, daño, objetivos, botín, construcción y guardado se validan en host.

## Consecuencias

- El cliente envía intenciones.
- Se requieren mensajes de error claros.
- Las pruebas incluyen un cliente malicioso o estados inválidos.
- La UI puede predecir feedback, pero no confirmar resultados permanentes.
