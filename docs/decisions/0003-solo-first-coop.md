# ADR-0003 — Solo-first, cooperativo integrado

- Estado: Accepted
- Fecha: 2026-08-02

## Decisión

Toda feature principal debe funcionar con una persona. Los jugadores adicionales sustituyen o complementan funciones NPC.

## Consecuencias

- Los raids escalan por capacidad real.
- No hay jobs obligatorios cubiertos solo por humanos.
- Los NPC necesitan una simulación mínima persistente.
- El juego no depende de llenar servidores.
