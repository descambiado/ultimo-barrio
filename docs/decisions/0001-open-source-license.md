# ADR-0001 — Licencia open source

- Estado: Accepted
- Fecha: 2026-08-02

## Contexto

El proyecto será multijugador, puede operar en servidores y busca contribuciones públicas. Se quiere evitar que un fork público significativo cierre todas sus mejoras.

## Decisión

Licenciar el código original bajo MPL-2.0.

## Consecuencias

- Las contribuciones deben ser compatibles.
- Los assets externos mantienen licencias independientes.
- Puede evaluarse dual licensing en el futuro.
- La marca y assets propios pueden gestionarse por separado.
