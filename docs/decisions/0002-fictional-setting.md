# ADR-0002 — Ambientación ficticia

- Estado: Accepted
- Fecha: 2026-08-02

## Contexto

La inspiración incluye resiliencia civil, barrios fronterizos, comercio clandestino y defensa vecinal.

## Decisión

Usar una ciudad, facciones, símbolos y cronología ficticios. No definir enemigos por nacionalidad, etnia o religión real.

## Consecuencias

- Mayor libertad creativa.
- Menor riesgo de propaganda o deshumanización.
- Arquitectura y cultura pueden mezclar referencias sin reconstruir víctimas reales.
