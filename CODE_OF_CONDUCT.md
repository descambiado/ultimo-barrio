# Código de conducta

Queremos una comunidad técnica, directa y respetuosa.

## Esperado

- Criticar código y decisiones, no personas.
- Explicar problemas con evidencia reproducible.
- Dar crédito a autores y dependencias.
- Ayudar a quienes empiezan sin rebajar el nivel técnico.
- Mantener discusiones políticas reales fuera del desarrollo del juego.
- Tratar la ambientación sensible con responsabilidad.

## No aceptado

- Acoso, amenazas o discriminación.
- Publicación de datos personales.
- Apropiación de trabajo ajeno.
- Uso del proyecto para propaganda contra colectivos reales.
- Sabotaje, backdoors o abuso de infraestructura.

Los mantenedores pueden moderar, cerrar contribuciones o retirar acceso cuando sea necesario.
