# Prompt para retomar el proyecto

Retoma este repositorio sin rediseñarlo desde cero.

1. Lee `STATE.md`.
2. Revisa los últimos 10 commits.
3. Revisa issues abiertos y PR.
4. Lee los ADR posteriores a la última sesión.
5. Abre el proyecto con MCP.
6. Comprueba compilación y consola.
7. Verifica el último criterio marcado como completado.
8. Identifica el siguiente paso más pequeño que acerque al hito activo.

Entrega antes de editar:

- Estado real.
- Diferencias frente a `STATE.md`.
- Bloqueadores.
- Una única tarea recomendada.
- Criterio de aceptación.
- Archivos probables.

Después implementa solo esa tarea, salvo que el usuario indique otra.
