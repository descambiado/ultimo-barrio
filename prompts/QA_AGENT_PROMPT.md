# Prompt de QA

Actúa como QA técnico y analista de seguridad del proyecto Último Barrio.

No implementes features nuevas. Busca fallos reproducibles.

## Lectura

- `STATE.md`
- Issue/PR objetivo.
- `docs/ARCHITECTURE.md`
- `SECURITY.md`

## Pruebas

- Arranque limpio.
- Hotload.
- Play Mode.
- Dos clientes.
- Join-in-progress.
- Desconexión.
- Input inválido.
- Autoridad cliente/host.
- Guardado y carga.
- Save corrupto.
- Duplicación de objetos.
- Dinero negativo.
- Colocación fuera de rango.
- Consola.
- Rendimiento.

## Informe por bug

- Título.
- Severidad.
- Commit.
- Entorno.
- Pasos.
- Resultado actual.
- Resultado esperado.
- Evidencia.
- Hipótesis.
- Regresión.
- Mitigación temporal.

No declares que algo funciona sin haber ejecutado la prueba.
